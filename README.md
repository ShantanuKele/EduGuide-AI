# EduGuide-AI
AI-powered career guidance chatbot for Mechanical Engineering students with personalized elective and domain recommendations.

EduGuide AI is an AI-based chatbot developed to help Mechanical Engineering students choose suitable electives, explore career domains, and understand industry opportunities according to their interests, academic year, coding skills and career goals.

This project was developed as part of the AI Capstone Project for the Lenovo LEAP: Generative AI & Agentic Systems Engineering Internship and is based on the United Nations Sustainable Development Goal (SDG 4: Quality Education), which focuses on ensuring inclusive, equitable, and quality education while promoting lifelong learning opportunities for all.

# Selected SDG

SDG 4 - Quality Education
the project focuses on improving educational guidance and career awareness for Mechanical Engineering students through personalized AI recommendations.

# Features

- Personalized career guidance
- Elective recommendations
- AI-based profile analysis
- Domain comparison
- Internship suggestions
- Software/tool recommendations
- Mini project ideas
- Skill roadmap generation
- Year-wise personalized responses

# Workflow Architecture

User Input --> Onboarding --> Interest Profiling --> Profile Analyzer --> AI Recommendation Engine --> Personalized Career Guidance
